12주차 스킬 검토 기록 — movie-rank

movie-rank 는 예시 스킬. 남이 만들어 보낸 스킬이라고 생각하고 읽을 것
설치하거나 실행하지 않고 읽기만 함
번호는 검토 기준 번호와 같음. 괄호 안의 "볼 곳"을 열어 보고 답할 것.


1. 전부 읽었나
   이 스킬 폴더에 파일이 몇 개 있나? 이름을 모두 적기
   (볼 곳: VS Code 탐색기에서 폴더를 모두 펼치기)
   답: 3개 — SKILL.md, LICENSE, scripts/top3.py. 세 파일 모두 열어 읽음

2. 설명대로만 하나
   이 스킬은 무엇을 하는 스킬인가? 한 줄로.
   top3.py 가 하는 일도 그 설명과 같은가?
   (볼 곳: SKILL.md 맨 위 description, scripts/top3.py)
   답: KOBIS 일별 박스오피스에서 특정 날짜의 1~3위 영화 제목을 알려 주는 스킬 (SKILL.md 3줄).
       top3.py 도 KOBIS 에 요청해 1~3위의 순위와 제목만 출력함 (top3.py 24줄) → 설명과 같은 일. 설명에 없는 일을 하는 줄은 없음.
       실행하라는 명령은 python .claude/skills/movie-rank/scripts/top3.py 날짜 (SKILL.md 13줄)

3. 바깥으로 보내는 곳
   이 스킬이 내 컴퓨터 밖의 서버에 연결하는 곳이 있나?
   있으면 그 주소와, 무엇을 보내는지 적기
   (볼 곳: Ctrl+Shift+F 로 http 검색. 파일 이름과 줄 번호)
   답: 있음. top3.py 10~11줄 https://www.kobis.or.kr/kobisopenapi/webservice/rest/boxoffice/searchDailyBoxOfficeList.json (영화진흥위원회) 한 곳뿐.
       top3.py 15줄 requests.get 으로 key(내 API 키)와 targetDt(날짜)를 보냄. curl, subprocess, open( 은 없음

4. 키와 비밀
   키를 코드에 직접 적어 두었나? 키는 어디서 읽어 오나?
   (볼 곳: Ctrl+Shift+F 로 key 검색. 파일 이름과 줄 번호)
   답: 직접 적지 않음. top3.py 8줄 from secret import API_KEY — 실행하는 프로젝트 폴더의 secret.py 에서 읽어 옴 (7줄에서 지금 폴더를 import 경로에 넣음).
       읽은 키는 15줄에서 kobis.or.kr 로만 보냄
